Slackとつなぐ

会社でSlackを使っているなら、こちら。手でやるのは2か所だけ。チャンネル作りと、いつでも返事ができる設定は自動です。

時間10分ほど
いるものSlackのワークスペース（無ければ途中で作れます）
注意会社のSlackでは、アプリを入れるのに管理者の許可が要ることがあります
英語の画面が出てきます。ボタンの名前は 英語（日本語の意味） の形で書いています。

手でやる2か所

  1. AIの分身（アプリ）を作る 設定係が、設定が入った状態の作成画面を開きます。
    1. AIを入れるワークスペースを選ぶ → Next（次へ）
    2. もう一度 Next → Create（作成）
    3. Install to Workspace（ワークスペースに入れる） → 許可する
    manifest: bot scopes = channels:history/read/manage/join, chat:write, files:read/write, users:read, reactions:write。Socket Mode 不使用（ポーリング方式）なので app-level token（xapp）は不要。
  2. 鍵をコピーして貼る 左の一覧の OAuth & Permissions（許可の設定） → Bot User OAuth Token（xoxb- で始まる）の Copy → 設定係の画面に貼り付けて return。 「User」ではなく「Bot」の方です。貼り付けても画面には何も出ません。

自動で進むこと

  • AI用のチャンネル作成（ここに書くとAIが返事）
  • いつでも返事ができる設定（Macが起きている間）
  • つながったかの確認：開いたチャンネルに「はじめまして」と送ると、AIが返事をします
Slackの無料プランでは、見られる会話の履歴が直近90日分になります。
鍵（xoxb- で始まる文字列）は、誰にも見せないでください。AIとの会話にも貼らないでください。
うまくいかないときは 困ったとき へ。
