fox-kit
入れ方DiscordSlack困ったとき

AI秘書を、1行で入れる。

あなたの仕事を手伝うAI秘書を、このパソコンに用意します。黒い画面に1行はり付けるだけで、あとは画面の質問に答えていけば終わります。

Claude Code を汎用FOXとして組み立てるインストーラ。本体・作法集（32項目）・資料品質ループ・保存先・Discord/Slack 接続まで。

はじめる前に

いるもの 1Mac（2020年以降のものがおすすめ）Windows 10／11 のパソコン（ふだん使っているアカウントで。管理者のパスワードを聞かれることがあります）
いるもの 2Claude の有料の契約（Pro／Max／Team）
無料のままでは使えません。会社で使うなら、会社で契約したもの
いるもの 3会社の Google アカウントと、使うなら Slack にログインできること
確認のコードが届くスマホを手元に
時間1時間ほど
途中で待つ時間があります。パソコンが眠らないよう、ふたは開けたままで

入れ方

  1. 「ターミナル」を開く キーボードの command を押しながら スペース を押し、「ターミナル」と打って return。文字だけの画面（黒か白）が開きます。 ⌘+Space → ターミナル
  2. 次の1行をコピーして、ターミナルに貼り付けて return
    /bin/zsh -c "$(curl -fsSL https://kinopy0918.github.io/fox-kit/get.sh)"
    ターミナルを使うのはここだけです。
  3. Appleの追加部品が必要と出たら「インストール」 初めて使うMacでは「コマンドライン・デベロッパ・ツールをインストールしますか？」と出ます。「インストール」→「同意する」を押して、終わるまで待ってください（10〜20分）。 素のMacでは xcode-select --install が走り、完了まで待ちます（python3 用）。
  4. ブラウザに「設定画面」が開く → あとは画面の案内どおり いまやることが画面の真ん中に1つだけ出ます。押していけば順に進みます（全10ステップ）。 名前を決める → AIのアカウントにログイン → パソコンの設定 → 資料の保存先（Googleドライブがおすすめ）→ Slack か Discord とつなぐ → AIと最初のお話、の順です。
  5. 終わったら、Slack・Discord で話しかける これからの用事も、困ったことも、つないだチャンネルで AI に話しかけるだけです。 この Mac の前では Antigravity（Claude Code 拡張入り）から指示するのが速い。 手順の詳しい写真は Discordとつなぐ／Slackとつなぐ にもあります。
  1. 「PowerShell」を開く 画面左下のスタートボタン（窓のマーク）を押し、「powershell」と打って Enter。青か黒の、文字だけの画面が開きます。
    （「管理者として実行」は選ばなくて大丈夫です）     Win キー → powershell（管理者でなくてよい）
  2. 次の1行をコピーして、PowerShell に貼り付けて Enter
    powershell -NoProfile -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol='Tls12';iex ([Text.Encoding]::UTF8.GetString((New-Object Net.WebClient).DownloadData('https://kinopy0918.github.io/fox-kit/get.ps1')))"
    貼り付けは、PowerShell の画面の上で右クリックでもできます。 irm | iex にしていないのは日本語の文字化け対策（バイトで取って UTF-8 で読む）。
  3. 質問に答える → 「変更を許可しますか？」には「はい」 名前などを聞かれたら、打ち込んで Enter。途中で AIが使う部品（Git・Python）と AI の本体が自動で入ります。そのたびに「このアプリがデバイスに変更を加えることを許可しますか？」と出たら「はい」を押してください。 winget で Git for Windows・Python 3.12、claude.ai/install.ps1 で本体。winget が無ければ公式インストーラに切り替え。
  4. AIのアカウントにログイン ブラウザが開きます。AIの契約をしたアカウントで「ログイン」→「許可」。コードが表示されたら、それを PowerShell の画面に貼り付けて Enter。 claude auth login
  5. AIと最初のお話（初期設定） AIが、あなたの仕事や資料の保存先（Googleドライブがおすすめ）について1問ずつ質問します。答えるだけで設定が進みます。 AIが「初期設定が終わりました」と言ったら、Ctrl を押しながら C を2回押して終わります。
  6. これからは スタートから「PowerShell」を開いて claude と打てば、いつでも AI と話せます。途中で入れた「Antigravity」があれば、その中の Claude のマークから話しかけるのがいちばん楽です。 ホーム（~）で claude、または Antigravity の Claude Code 拡張。
Windows 版でまだできないこと：スマホ（Slack・Discord）から AI に話しかける仕組み、画像づくりの鍵の登録、ブラウザで進める設定画面。これらは今は Mac 版だけです。パソコンの前で使う AI 秘書としては、Mac 版と同じ作法・資料のチェック役・保存先の整理が入ります。
途中で止まっても大丈夫です。同じ1行をもう一度貼り付けると、設定画面が続きのところから開きます始まります。
このAIは、いちいち「実行してよいですか？」と聞かずに作業を進める設定になります。お金が動くこと・社外に送ること・あなたしか知らない判断は、必ず先に確認する決まりが入っています。

会社で配るとき（質問を省く）

FOX_LEVEL=beginner FOX_OWNER="山田さん" FOX_AGENT="ヤマダAI" FOX_MACHINE="事務所のMac" FOX_ROLE="経理の自動化" \ /bin/zsh -c "$(curl -fsSL https://kinopy0918.github.io/fox-kit/get.sh)"
変数意味
FOX_LEVELbeginner（専門用語なし）／expert
FOX_PROFILE会社ごとの規則（rules/*.md を含む tar.gz のURLかフォルダ）。CLAUDE.md から常時読み込み
FOX_REMOTE=1 ＋ FOX_SSH_KEY遠隔保守用の Tailscale＋SSH
FOX_DEDICATED=1専用機：電源接続中はスリープしない
FOX_RESET=1覚えた答え（~/.config/fox-kit/state.env）を消して最初から

入るもの

~/.claude/CLAUDE.md人格（名前・持ち主・役割）＋ 作法の読み込み
~/.claude/rules/craft.md（作法32項目）・talk-style.md・storage.md（保存と探し方）・company.md
~/.claude/skills/fox-setup（初期設定）・shiryo-review-loop（資料の品質ループ）
~/Tools/fox-bridge（Discord/Slack）ほか汎用ツール
中身はすべて GitHub で読めます。
