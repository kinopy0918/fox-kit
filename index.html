fox-kit
入れ方DiscordSlack困ったとき

AI秘書を、1行で入れる。

あなたの仕事を手伝うAI秘書を、このMacに用意します。黒い画面に1行はり付けるだけで、あとは画面の質問に答えていけば終わります。

Claude Code を汎用FOXとして組み立てるインストーラ。本体・作法集（32項目）・資料品質ループ・保存先・Discord/Slack 接続まで。

はじめる前に（3つだけ）

いるもの 1Mac（2020年以降のものがおすすめ）
いるもの 2Claude の契約（Pro／Max／Team）
会社で使うなら、会社で契約したもの
時間20〜30分
パソコンの画面を2つ並べられると楽です

入れ方

  1. 「ターミナル」を開く キーボードの command を押しながら スペース を押し、「ターミナル」と打って return。文字だけの画面（黒か白）が開きます。 ⌘+Space → ターミナル
  2. 次の1行をコピーして、ターミナルに貼り付けて return
    /bin/zsh -c "$(curl -fsSL https://kinopy0918.github.io/fox-kit/get.sh)"
  3. 画面の質問に答える 最初に「はじめてか・慣れているか」を聞かれます。「1（はじめて）」を選ぶと、この先の案内も、入れたあとのAIの話し方も、むずかしい言葉を使わなくなります。 続けて、あなたのお名前・AIの名前・このMacの呼び方・主な用途を聞かれます。
  4. Appleの追加部品が必要と出たら「インストール」 初めて使うMacでは「コマンドライン・デベロッパ・ツールをインストールしますか？」と出ることがあります。「インストール」を押して、終わるまで待ってください（10〜20分）。 素のMacでは xcode-select --install が走り、完了まで待ちます（python3 用）。
  5. ブラウザでログイン AIの契約をしたアカウントで「ログイン」→「許可」。会社のMacなら会社のアカウントで。
  6. AIとの最初のお話（初期設定） AIが、仕事のこと・使っている道具・資料の保存先・任せたい仕事を1つずつ聞いてきます。答えるだけで設定が進みます。 資料の保存先は「Googleドライブ」をおすすめします（アプリが無ければAIが入れます）。
  7. スマホからも話せるようにする（おすすめ） 初期設定の途中で「Discord か Slack か」を選ぶと、つなぐための画面が開きます。 手順は Discordとつなぐ／Slackとつなぐ に1つずつ書いてあります。
途中で止まっても大丈夫です。同じ1行をもう一度貼り付けると、答えた内容を覚えていて、続きから始まります。
このAIは、いちいち「実行してよいですか？」と聞かずに作業を進める設定になります。お金が動くこと・社外に送ること・あなたしか知らない判断は、必ず先に確認する決まりが入っています。

会社で配るとき（質問を省く）

FOX_LEVEL=beginner FOX_OWNER="山田さん" FOX_AGENT="ヤマダAI" FOX_MACHINE="事務所のMac" FOX_ROLE="経理の自動化" \ /bin/zsh -c "$(curl -fsSL https://kinopy0918.github.io/fox-kit/get.sh)"
変数意味
FOX_LEVELbeginner（専門用語なし）／expert
FOX_PROFILE会社ごとの規則（rules/*.md を含む tar.gz のURLかフォルダ）。CLAUDE.md から常時読み込み
FOX_REMOTE=1 ＋ FOX_SSH_KEY遠隔保守用の Tailscale＋SSH
FOX_DEDICATED=1専用機：電源接続中はスリープしない
FOX_RESET=1覚えた答え（~/.config/fox-kit/state.env）を消して最初から

入るもの

~/.claude/CLAUDE.md人格（名前・持ち主・役割）＋ 作法の読み込み
~/.claude/rules/craft.md（作法32項目）・talk-style.md・storage.md（保存と探し方）・company.md
~/.claude/skills/fox-setup（初期設定）・shiryo-review-loop（資料の品質ループ）
~/Tools/fox-bridge（Discord/Slack）ほか汎用ツール
中身はすべて GitHub で読めます。
