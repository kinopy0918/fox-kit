Discordとつなぐ

つなぐと、スマホのDiscordからAIに話しかけられるようになります。手でやるのは3か所だけ。残り（チャンネル作り・いつでも返事できる設定・つながったかの確認）は自動です。

時間10分ほど
いるものDiscordのアカウント（無ければ途中で作れます）
始め方初期設定で「Discord」を選ぶと、設定係の画面が開きます。あとからなら「つなぐ」をダブルクリック。~/Tools/fox-bridge/つなぐ.command または python3 connect.py
英語の画面が出てきます。ボタンの名前は 英語（日本語の意味） の形で書いています。

手でやる3か所

  1. AIの部屋（サーバー）を用意する 新しく作るのがおすすめです。画面の左はしの ＋（サーバーを追加） →「オリジナルの作成」→「自分と友達のため」→ 名前（例：「ヤマダAIの部屋」）を入れて「新規作成」。
    いつも使っているサーバーに入れることもできます。     新規作成 or 既存（管理者権限が必要）。
  2. AIの分身（ボット）を作って、鍵をコピーする 設定係が 開発者用の画面 を開きます。
    1. 右上の New Application（新しいアプリ）
    2. 名前にAIの名前を入れ、同意にチェック → Create（作成）
    3. 左の一覧の Bot
    4. Reset Token（鍵を作り直す） → Yes, do it!（はい）（パスワードを聞かれたら入れる）
    5. 出てきた長い文字列の Copy（コピー） → 設定係の画面に貼り付けて return
    貼り付けても画面には何も出ません（見えないようにしています）。そのまま return を押して大丈夫です。
  3. ボットをサーバーに招待する 設定係が招待の画面を開きます。「サーバーに追加」で1のサーバーを選び → はい → 認証。 権限は固定済み（チャンネル閲覧・送信・履歴・添付・埋め込み・チャンネル管理・リアクション）。

自動で進むこと

  • AIが文章を読めるようにする設定 （PATCH /applications/@me で限定版 Message Content を有効化。できない場合だけ、Botの画面で MESSAGE CONTENT INTENT をオン→Save Changes を案内）
  • AIの名前のカテゴリと、#相談（ここに書くとAIが返事）・#お知らせ・#記録 のチャンネル作成
  • いつでも返事ができる設定（Macが起きている間）
  • つながったかの確認：#相談 に「はじめまして」と送ると、AIが返事をします
鍵（長い文字列）は、誰にも見せないでください。AIとの会話やチャットにも貼らないでください。貼ってしまったら、手順2の Reset Token で作り直せば古い鍵は使えなくなります。
Macのふたを閉じる・電源を切ると、返事が止まります。いつでも返事をさせたいMacは、電源につないだままにしてください。
うまくいかないときは 困ったとき へ。
