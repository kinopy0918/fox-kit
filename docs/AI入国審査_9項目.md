# AI入国審査 9項目 — 会社で Claude を使う前に

会社の仕事に AI を入れる前に、情報システムの担当者が確かめる9項目です。
このパソコンで確かめられる分は、ターミナルで `fox-kit check` と打つと ○△× で出ます。

> 2026年11月時点の Anthropic 公式ドキュメント（[データの使い方](https://code.claude.com/docs/en/data-usage)・[設定](https://code.claude.com/docs/en/settings)）をもとにしています。契約で決まる数字（日数・時間）は、必ず自社の契約書で確かめてください。

## 結論

- 仕事に使うなら、**会社の契約（Team / Enterprise / API）にそろえる**。個人プラン（Pro / Max）のままだと、学習・契約の項目が「本人まかせ」になる
- どのプランでも、**読ませる場所を絞る・確認を飛ばしすぎない・パソコンを暗号化する**
- 誰が何をしたかの記録（監査ログ）まで要るなら Enterprise

## 9項目

### 1. 行き先 — 渡したデータはどこへ行く？
- Claude Code はパソコンの中で動くが、指示・AIが読んだファイル・答えは Anthropic のサーバーに送られる（通信は TLS 1.2 以上で暗号化）
- **読ませたファイルは外に出る**と考える
- キットの対策：作業用のフォルダで起動する作法。デスクトップ・ダウンロードへの書き捨てを止める見張り
- あなたがやること：ダウンロード・デスクトップに仕事の資料や知らないファイルを置きっぱなしにしない

### 2. 学習 — 会話が AI の学習に使われる？
- **Team / Enterprise / API**：学習に使われない
- **個人プラン（Free / Pro / Max）**：本人の設定しだい。オンだと学習に使われ、会話は**5年**残る。オフなら30日
- 会社からは社員一人ひとりの設定が見えない
- あなたがやること：個人プランなら [claude.ai/settings/data-privacy-controls](https://claude.ai/settings/data-privacy-controls) で「Claude の改善に協力する」をオフ

### 3. 記録 — 会話はどこに、いつまで残る？
- サーバー側：会社向けは標準30日。個人は上のとおり
- **パソコン側：会話の記録が `~/.claude/projects/` に暗号化されずに残る**（既定30日）
- キットの対策：残す日数を**14日**にしている（`cleanupPeriodDays`）
- あなたがやること：パソコンの暗号化（5番）

### 4. ログインと権限 — 誰が、どこまで触れる？
- Team / Enterprise は会社のアカウントでまとめてログインできる。管理者が配る設定で、会社の組織以外ではログインできないようにもできる
- キットの既定は「確認なしで実行する」。代わりに**お金・社外への送信・取り消せない操作は必ず人に確かめる**作法と、危ない操作を止める見張りを入れている
- 新入社員と同じく、はじめは読むだけ・専用のフォルダだけ・管理者アカウントをつながない
- 会社で「確認なしの実行」を禁止したいときは、管理者が配る設定（managed settings）で止められる

### 5. 暗号化 — 置いてある間・運ぶ間は守られる？
- サーバー側：保存中は AES-256、通信は TLS 1.2 以上
- 暗号化が守るのは「置いてある間」と「運ぶ間」だけ。AI は作業のときに開けて読む
- **パソコン側は自分で守る**：Mac は FileVault をオン（システム設定 → プライバシーとセキュリティ → FileVault）。`fox-kit check` で確かめられる

### 6. 第三者の認証 — 安全を誰が保証している？
- Anthropic は外部の監査を受けている。報告書は [Trust Center](https://trust.anthropic.com) で申し込む
- 対象は会社向けのサービスと API。個人プランは対象外

### 7. 委託先 — Anthropic 以外の会社もデータに触る？
- クラウドの会社などの委託先が関わる。一覧は公開されている
- 委託先が増えるときの知らせ・異議の出し方は、会社向け契約の取り決め（データ処理の取り決め）に書かれている

### 8. 事故と解約 — もしものときの約束は？
- 漏えいに気づいたときの連絡・解約後のデータ削除は、会社向け契約の取り決めに書かれている
- 期限（何時間以内・何日以内）は契約書で確かめる

### 9. AI 特有のリスク — いま一番事件が起きている所
- 道は3つ：**偽物の連携ツールをつなぐ／AI が隠された命令にだまされる／AI に権限を渡しすぎる**
- 例：ダウンロードフォルダに置かれた「AIへの指示書」を読ませて乗っ取る実験が報告されている
- キットの対策：危ない操作（消す・送る・公開する）と秘密の持ち出しを実行前に止める見張り。スキルを入れる前に中身を読む見張り
- あなたがやること：
  - 連携ツール（MCP）は知っている物だけ。`fox-kit check` で一覧が出る。知らない物は `claude mcp remove <名前>`
  - 「このフォルダを信頼しますか？」は中身を見てから
  - 知らない人からもらったフォルダで AI を起動しない
