# 初期設定の聞き取り

インストールが終わった直後の持ち主と、最初の会話をする。**聞いた答えをその場で規則と記憶に書き、最後に1件試しに仕事をして終える。**
話し方は `~/.claude/rules/talk-style.md` に従う（初心者なら専門用語を使わない）。
記憶の場所は CLAUDE.md に書かれたフォルダ（以下「記憶フォルダ」）。書き方は CLAUDE.md の「記憶を残す」に従う。

## Windows のとき

このパソコンが Windows なら（`uname` が MINGW/MSYS を返す、またはパスが `C:\` で始まる）、次だけ読み替える:
- 「Mac」→「パソコン」。フォルダを見せるときは `open` でなく `explorer "<場所>"`（パスは `\` 区切り）。
- 3-2 の Google ドライブのアプリは `storage.py install-gdrive` が Windows 用の入れ方で入れる（「変更を許可しますか？」に「はい」）。ログイン後はエクスプローラーの左に「Google Drive (G:)」が出る。
- 3-6 で記憶をつなぎ込めなかったと出たら、そのまま進める（記憶はこのパソコンに残る、と一言だけ伝える）。
- 5 の Discord/Slack 接続は、つなぐ.command の代わりに次のどちらかを AI が PowerShell で開く（持ち主にコマンドを打たせない）。
  Windows は PowerShell で、`~/.config/fox-kit/wizard.json` があれば設定画面を開く：`$py = (Get-Command pythonw -All | Where-Object Source -notlike '*WindowsApps*' | Select-Object -First 1).Source; Start-Process -FilePath $py -ArgumentList ('"' + "$HOME\Tools\fox-kit\wizard\server.py" + '"')`。無ければ（黒い画面で入れた人）設定画面は使わず、Discord/Slack は設定係の窓で：`$py = (Get-Command python -All | Where-Object Source -notlike '*WindowsApps*' | Select-Object -First 1).Source; Start-Process -FilePath $py -ArgumentList ('"' + "$HOME\Tools\fox-kit\tools\fox-bridge\connect.py" + '"')`（新しい黒い窓で設定係が開く）。
  設定画面なら「左の一覧の『スマホから話せるように』を押して、画面の案内どおりに」、設定係の窓なら「窓の案内どおりに」進めてもらい、終わったら『できた』と送ってもらう。
  確認は `$py = (Get-Command python -All | Where-Object Source -notlike '*WindowsApps*' | Select-Object -First 1).Source; & $py "$HOME\Tools\fox-kit\tools\fox-bridge\connect.py" --status`。
  鍵は Windows の資格情報マネージャーに入り、常駐はタスク スケジューラ（名前 fox-bridge・サインインで起動・止まっても5分以内に起き直す）。「パソコンにサインインしている間だけ返事をする」と添える。
  「あとでできること」に入れるときは「AI に『スマホから頼めるようにしたい』と言う」と書く。
- 4.5 の締めの1行で「画像づくり」を挙げない（Windows では使えない）。「会議・調べもの・資料づくり」にする。

## 進め方の約束

- 1回に聞くのは**1問だけ**。選べる質問は選択肢で出す（AskUserQuestion が使えるなら使う）。
- 「わからない」「あとで」はそのまま受け取って先へ進む。空欄は「未定」と記憶に書く。
- 各段が終わるたびに 記憶フォルダの `setup-progress.md` に「どこまで終わったか」を書く。途中で止まっても、次に呼ばれたらそこから再開する（最初に必ず読む）。
- 全部で**20分**を目安にする（スマホとつなぐ 5 は別に10分）。長くなりそうなら、残りを「あとでできること」に回す。
- 聞いたことを復唱しない。「○○で進めます」と1行だけ返して次へ。
- **0.5 で下書きができたら、1・2・4 はゼロから聞かない。**下書きを見せて「こうですか？」と確かめ、記録から分からなかった所だけ聞く。

## 0. はじめのあいさつ

名前を名乗り、「これからいくつか質問して、あなた用に設定します。20分ほどです（スマホとつなぐ場合はもう10分）。途中でやめても続きからできます」と伝える。

## 0.5. 前に使っていたAIの記録から、下書きを作る

ChatGPT・Gemini・Claude を使っていた人には、同じことを一から聞かない。先に記録を読み、「こうですか？」と確かめる形にする。

1. `python3 ~/.claude/skills/fox-setup/history.py scan` を実行する（中身は出ない。見つかった記録の数と期間だけ）。
2. 選択肢で聞く：「前に ChatGPT・Gemini・Claude を使っていましたか？　使っていたなら、その記録から、あなたについての下書きを先に作ります。記録はこのパソコンの中から探し、読むのはあなたが『いい』と言ってからです」
   - **ChatGPT を使っていた** → 次の1文をそのまま見せ、「ChatGPT（スマホでもパソコンでも）に送って、返ってきた文をここに貼ってください」と頼む：
     `私について覚えていることを、仕事・会社・役割・よく一緒に仕事をする人・使っている道具・よく頼むこと・手間がかかっていること・話し方の好み に分けて、箇条書きで全部書き出してください。`
   - **Gemini・claude.ai を使っていた** → 上と同じ1文を、Gemini（claude.ai）に送って、返ってきた文を貼ってもらう。
   - 書き出したファイルがあれば、それも読める（ダウンロードのフォルダに置いてもらう。どちらも届くまで数分〜数日かかるので、待たせない。無ければ上の1文で十分）：
     ChatGPT は「設定 → データコントロール → データをエクスポート」で届く zip（scan の `chatgpt_export`）。
     Gemini は Google の「データ エクスポート（takeout.google.com）」で「マイ アクティビティ」の **Gemini アプリ** を選び、形式を **JSON** にした zip（scan の `gemini_takeout`）。
   - **このパソコンで Claude Code・Codex・Gemini CLI を使っていた**、または書き出したファイルを置いた（scan のどれかが1件以上）→ 許しをもらってから
     `python3 ~/.claude/skills/fox-setup/history.py extract` を実行する（持ち主が書いた文だけを新しい順に、2万4千字まで。AIの返事・道具の出力・自動要約・この初期設定の会話は読まない。代表的な形式の鍵・メール・電話番号は伏せてある）。Windows で `python3` が無ければ `python`。
     出力の最後に「読めなかったもの」があれば、「一部の記録は読めませんでした」と一言伝える。
   - **使っていない／読まないでほしい** → そのまま 1 へ（今まで通り1問ずつ聞く）。
3. 読んだものから、1・2・4 で聞く項目（会社と事業・役割・よく一緒に仕事をする人・使っている道具・手間のかかっている仕事・話し方の好み）の**下書き**を作る。
   - 記録に**はっきり書いてあること**だけを書く。推測は書かない（「たぶん経理担当」は書かない）。分からない項目は空けておく。
   - 他の人の個人情報（電話番号・住所・お客様の詳しい事情）や、パスワード・鍵は下書きに入れない。
4. 下書きを**1項目ずつ**「こうですか？」と出す。選択肢は「合っている」「直す（正しくは…）」「書かないで」の3つ。
   - 一度に全部を並べない。1回に1項目（初心者のとき）。慣れている人には、まとめて見せて「違う所だけ教えてください」でよい。
   - 「合っている」になったものだけを、1・2・4 の書き先（`user_owner.md`・`project_company.md`・`reference_people.md`・`reference_tools.md`・`project_wishlist.md`）に書く。
5. 話し方の好み（「結論から」「短く」など）が分かったら、確かめてから `feedback_talk.md` に書く。
6. 貼ってもらった文・抜き出した記録そのものは、記憶にも保存先にも書き写さない（確かめた結果だけを書く）。この会話の記録には残る、と聞かれたら正直に答える。

## 1. お仕事のこと（→ 記憶）

0.5 で確かめ済みの項目は飛ばす。

1. 会社（お店・団体）の名前と、何をしているところか
2. あなたの役割（例：社長／経理担当／店長）
3. よく一緒に仕事をする人（名前と役割。3人まで）

→ 記憶に `user_owner.md`（持ち主の役割）と `project_company.md`（会社と事業）を書く。人の名前は `reference_people.md`。

## 2. 使っている道具（→ 記憶）

0.5 で分かっている道具は「〇〇と〇〇をお使いですね？」と1回だけ確かめ、残りだけ選択肢で聞く。

選択肢で聞く（複数可）:
- メール：Gmail／Outlook／その他
- 予定表：Googleカレンダー／Outlook／その他
- 社内の連絡：LINE／Slack／Discord／Chatwork／その他
- ファイル：Googleドライブ／OneDrive／Dropbox／このMacだけ
- 会計・業務のソフト（自由記述）

→ `reference_tools.md` に書く。GmailやGoogleカレンダーを使っているなら、「Claude の設定画面（claude.ai の『コネクタ』）でつなぐと、AIが直接読めるようになります」と**あとでできること**に入れる（ここでは設定させない）。

## 3. 保存先を決める（チュートリアル形式・→ フォルダと規則）

ここは**選択肢を1つずつ出して、選んでもらいながら組み立てる**。各選択肢には「おすすめ」と、選ぶと何が変わるかを1行添える。

**3-1. 場所を調べる**
`python3 ~/.claude/skills/fox-setup/storage.py detect` を実行する（`folders` と `google_drive_app_installed` が返る）。

**3-2. Google ドライブのアプリ（2 で Google を使っていると答えた、かつアプリが無いとき）**
「パソコン用の Google ドライブのアプリを入れると、AIが作ったものが自動でクラウドに保存され、スマホや他の人からも見られます。入れますか？」
- はい（おすすめ）→ `python3 ~/.claude/skills/fox-setup/storage.py install-gdrive` を実行。Macのパスワードの画面が出ることを先に伝える。
  入ったら「開いた画面で**会社の** Google アカウントでログインしてください。『ストリーミング』か『ミラーリング』かを聞かれたら**ストリーミング**を選んでください（パソコンに丸ごと置かない＝重くならない）。終わったら『できた』と送ってください」と待つ。
  「できた」を受けたら、もう一度 detect して、Google ドライブが見つかることを確かめる（見つからなければ、ログインが済んでいるか1つずつ確かめる）。
- いいえ → 見つかった他の場所から選ぶ。

**3-3. どこに置くか**
見つかった場所を選択肢で出す。**会社のアカウントのものを先頭に（おすすめ）**。共有ドライブがあれば「チームで見られる」と添える。
「このMacの中だけ」は「Macが壊れると消えます」と添えて最後に。

**3-4. フォルダの形（聞かない）**
番号つき11フォルダ（仕組み・案件・議事録・記録・手順と自動化・テンプレート・タスク・メモと調査・AIの記憶・目標・保管庫）で作る。
細かく分けるほどAIが探す範囲をしぼれて速く正確になるので、簡単な形は勧めない（持ち主から「少なくしたい」と言われたときだけ `--layout simple`）。

**3-5. AIの探し方（目次のしくみ）**
説明：「各フォルダに**目次**を自動で作ります。AIは目次を見て、関係のあるところだけを読みに行くので、速く・正確に探せます」
- **作業が終わるたびに目次を自動で更新（おすすめ）**
- **自分で頼んだときだけ更新**（「目次を更新して」と言う）

**3-6. 組み立てる**
選んだ内容で実行する（AIの記憶もその場所に置く＝Macが壊れても残り、人も中身を見られる）:
```
python3 ~/.claude/skills/fox-setup/storage.py apply --root "<3-3の場所>" --agent "<自分の名前>" \
  --layout fox --memory-in-root [--auto-index]
```
「このMacの中だけ」のときは `--memory-in-root` を付けない。
組み立てたら、`~/.local/bin/vault-rag` があれば `~/.local/bin/vault-rag index` を裏で実行する（意味で探すための索引。
作らないと翌朝の自動更新まで「保存先がまだ検索で使えません」になる）。
できたフォルダを `open` で開いて見せ、「ここに整理して置きます。いちばん上の『_全体の目次』がAIの入口です」と1行で伝える。
AIの記憶を置いたフォルダは、見られる人が中身も見られることを一言添える（パスワードや個人情報は記憶に書かない決まりがある、とも）。

## 4. 任せたい仕事（→ 記憶）

「いちばん手間がかかっている仕事」を3つまで聞く（0.5 の記録によく出てきた頼みごとがあれば、「よく〇〇を頼んでいましたね。これは手間のかかる仕事ですか？」と先に出す）。それぞれ「どのくらいの頻度で・どのくらい時間がかかるか」も聞く。
→ `project_wishlist.md` に、手間の大きい順に並べて書く。これが今後の自動化の候補一覧になる。

## 4.5. 秘書としてできることを提案する（→ 記憶）

入れた直後の人は「で、何を頼めばいいの？」で止まる。こちらから勧める。
`~/.claude/skills/fox-setup/secretary-menu.md` を読み、その中の「勧め方の決まり」に従って、
1〜4 の答え（役割・使っている道具・手間のかかる仕事）から**3つだけ**選ぶ。

1. 「あなたのお仕事だと、こんなことをお手伝いできます」と前置きして、3つを選択肢で出す（複数選んでよい）。
   各選択肢＝名前＋やることを1行＋話しかけ方の例。「必要なもの」が足りない項目は「〇〇をつなぐと使えます」と添える。
2. 選ばれたものを `project_wishlist.md` の「やってみたいこと」に、話しかけ方の例ごと書く。
3. 「ほかにも、会議・調べもの・画像づくりなども頼めます。『何ができる？』と聞けばいつでも出します」と1行だけ添える。

## 5. AIとのやり取りの場所（→ 記憶・接続）

選択肢で聞く:
- **Discord（おすすめ）**：無料・スマホでも使いやすい
- **Slack**：会社で既に使っているなら
- **いまはこの画面だけでよい**

Discord か Slack を選んだら、「スマホからでもAIと話せるようにする設定を、別の画面で一緒に進めます（10分ほど）」と伝えて、
`open ~/Tools/fox-bridge/つなぐ.command` を実行する（設定係の画面が新しく開く）。
- 設定係が、アカウント・サーバー（部屋）の作成／既存の選択・ボットの作成・招待・チャンネル作成・常駐・往復テストまで、画面を開いて1つずつ案内する。
- 鍵（トークン）は設定係の画面にだけ貼ってもらう。**この会話には貼らせない**（貼られたら「鍵は会話に書かないでください。設定係の画面に貼ってください」と伝え、記憶に書かない）。
- 終わったら「できた」と送ってもらい、`python3 ~/Tools/fox-bridge/connect.py --status` で「常駐: 動いています」を確かめる。
- 途中で止まったら、同じファイルを開けば最初からやり直せる、と伝える。
「いまはこの画面だけ」を選んだら、**あとでできること**に「Discord/Slack とつなぐ：`~/Tools/fox-bridge/つなぐ.command` をダブルクリック」を入れる。
→ `project_channel.md` に、選んだ場所と結果を書く。

## 6. 決まりごと（→ 規則）

`~/.claude/skills/fox-setup/company-template.md` を土台に、会社の決まりを1枚作る。
1. 「お金が動くこと・社外に送ること・あなたしか知らない判断は、必ず先に確認します」と伝え、ほかに**必ず確認してほしいこと**があるか聞く。
2. 会社で「これはしないで」という決まりがあるか聞く（例：お客様の名前を外に出さない）。
3. AIの設定や困りごとの窓口（人の名前）を聞く。
→ テンプレートの `{{COMPANY}}`（1の会社名）・`{{STORAGE}}`（3の保存先）・`{{EXTRA_CONFIRM}}`・`{{DONTS}}`・`{{CONTACT}}` を埋めて
`~/.claude/rules/company.md` に書く（既にあれば、足りない所だけ足す）。CLAUDE.md に `@~/.claude/rules/company.md` が無ければ足す。
答えが無い欄は「（まだ決まっていません）」と書いて残す。

## 7. 試しにやってみる

4.5 で選ばれたもの（無ければ 4 で聞いた仕事）のうち、**今すぐ小さく試せるもの**を1つ選んで実際にやる。つなぐ設定が要るものは後回しにして、要らないものを選ぶ（例：会社の紹介文を下書きして保存先の `07_メモ・調査/` に置き、開いて見せる。簡単な形で作った人は `03_調査・資料/`）。
試せるものが無ければ、「明日やることのメモ」を一緒に作って `06_タスク/`（簡単な形なら `02_議事録・メモ/`）に置く。

## 8. まとめ

3つの塊で短く伝える:
1. 設定できたこと（名前・保存先・やり取りの場所）
2. **あとでできること**（コネクタ・同期アプリ・Discord/Slack接続など。番号つき・各1行）
3. 次に話しかけるときの例＝4.5 で選ばれた項目の「話しかけ方の例」をそのまま並べる（「この文をそのまま言えば動きます」）

最後に 記憶フォルダの `setup-progress.md` を「完了」にし、`MEMORY.md` の索引に書いた記憶がすべて載っているか確かめる。

## やってはいけない

- 一度に複数の質問をする／専門用語で聞く（初心者のとき）
- 答えを推測で埋める（会社の事業・人の名前・金額）。0.5 の下書きも、持ち主が「合っている」と言うまでは記憶に書かない
- 前のAIの記録を、許しをもらう前に読む／貼ってもらった文や記録そのものを保存する
- この場で有料サービスの契約やアカウント作成を進める（案内だけにする）
- パスワードを聞く・記憶に書く
