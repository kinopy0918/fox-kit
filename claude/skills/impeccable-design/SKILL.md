# Impeccable Design — 視覚の基礎を固める

「AIっぽい・凡庸」の正体は、ほぼ**余白・タイポ・整列の甘さ**。派手な装飾ではなく、土台の一貫性で上質さは決まる。以下を毎回強制する。

## 1. スペーシング（最重要）

- **4px ベースのスケールだけ使う**: 4, 8, 12, 16, 24, 32, 48, 64, 96, 128。半端な値（13px, 27px…）を禁止。
- **余白は「足りない」より「多すぎる」寄りに**。素人は詰めすぎ。プロは呼吸させる。特にセクション間（80–160px）とコンテナの内側パディング。
- **関連する要素は近く、無関係な要素は遠く**（近接の原則）。ラベルと入力欄は近づけ、グループ間は離す。
- 一貫した**コンテナ最大幅**（本文系 640–768px、広いレイアウト 1100–1280px）＋左右パディング（モバイル16–24px）。
- 余白は「なんとなく」で置かない。スケールから選ぶ。

## 2. タイポグラフィ

- **タイプスケールを使う**（例: 12, 14, 16, 18, 20, 24, 30, 36, 48, 60, 72px。比率 1.2–1.25）。サイズを乱発しない。**3–4段階**で十分。
- **本文 16px 以上**、line-height 1.5–1.7。見出しは行間を詰める（1.1–1.25）。
- **行長（measure）45–75文字**。広い画面で本文を端から端まで流さない（`max-width: 65ch`）。
- **太さでヒエラルキーを作る**: 見出し 600–700、本文 400、補助テキスト 400＋色を薄く。やたら bold を多用しない。
- 見出しは **letter-spacing をわずかに詰める**（-0.01〜-0.02em）。大きい文字ほど効く。
- フォントは**1〜2種**まで。良い既定: Inter / Geist / system-ui（sans）、本文に上質さが欲しければ可変フォント。日本語なら Noto Sans JP / ヒラギノ。
- 数字が並ぶUI（価格・表）は `font-variant-numeric: tabular-nums`。

## 3. カラー

- **限定パレット**: 中立色（グレー）5–8段階 ＋ アクセント1色（必要なら2色目）。色を増やすほど安っぽくなる。
- **真っ黒・真っ白を避ける**。テキストは `#0a0a0a`〜`#171717`、背景は `#fafafa` 等。わずかに色味を入れると上品。
- **セマンティックトークン**で管理（`--bg`, `--fg`, `--muted`, `--border`, `--accent`）。生のhexを散らさない。
- コントラスト: 本文 4.5:1、大きい文字 3:1 以上（WCAG AA）。薄すぎる灰色テキストに注意。
- ダークモード対応なら、白を反転せず**専用の中立色**を組む。

## 4. レイアウト・整列

- **すべてグリッド/8pxに揃える**。光学的にズレて見える要素は微調整（optical alignment）。
- **左揃えを基本に**。中央揃えは短いヒーロー見出し等に限定。長文の中央揃えは読みにくい。
- 視覚的な**列・行のラインを通す**。ボタン・カード・アイコンの端を揃える。
- カードやセクションで**繰り返しパターンを統一**（同じ角丸・同じ影・同じパディング）。

## 5. ディテール（差がつく所）

- **角丸を統一**（例: 小要素 6–8px、カード 12–16px、全体で1つの系統）。混在させない。
- **影は控えめ・多層**。`0 1px 2px rgba(0,0,0,.06), 0 4px 12px rgba(0,0,0,.08)` のように薄く重ねる。一発の濃い影は安っぽい。
- **境界線は薄く**（`rgba(0,0,0,0.08)` 系）。影と線を両方使わず、どちらかで分離。
- アイコンサイズと太さを揃える（混在禁止）。Lucide など1セットで統一。
- フォーカスリング・hover・disabled など**状態を必ずデザイン**する。
- 空状態・ローディング・エラーも手を抜かない。

## やってはいけない（generic の典型）

- 半端な余白、詰めすぎのセクション。
- 紫グラデ＋多色＋濃い影の「AIテンプレ」感。
- フォントサイズ・太さ・色のバラつき。
- 本文を画面幅いっぱいに流す。
- 角丸・影・パディングがカードごとにバラバラ。
- すべて中央揃え。

## 仕上げQAチェック

- [ ] 全余白が4pxスケールに乗っているか
- [ ] フォントサイズは3–4段階に収まっているか／本文16px以上・行長65ch前後か
- [ ] 色は中立＋アクセント1で限定されているか／真っ黒真っ白を避けたか
- [ ] 角丸・影・パディングが全体で統一されているか
- [ ] 左揃え基準で、要素の端が揃っているか
- [ ] hover/focus/disabled/空/ローディング状態があるか
- [ ] コントラストAAを満たすか
