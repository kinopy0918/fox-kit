# スペース（用途別の小さな台帳）

旅行の段取り・企画のストック・買うものリストのように、**1つの用途に1つのファイル**を作り、会話で出し入れする。
アプリを作らない。Markdown 1枚で済ませる（スマホの Google ドライブや Obsidian でもそのまま読める）。

## 置き場所と形

- 場所：保存先の `スペース/<名前>.md`（保存先は `~/.config/fox-kit/storage.json` の `base`。無ければ `~/Documents`）
- 名前は持ち主の言葉のまま短く（例：`YouTube企画ストック`・`ラスベガス出張`・`買うもの`）
- 形は下の型を使う。「状態」は見出し、「1件」は `- [ ]` の1行。足す列は ` — ` で区切って1行に収める

```markdown
---
summary: <何のためのスペースか 1行>
updated: <YYYY-MM-DD>
---
# <名前>

## 候補
- [ ] 〇〇 — メモ（出どころの URL があれば最後に）

## 進行中

## 済み
- [x] 〇〇 — 済んだ日
```

用途に合わせて見出しだけ変える（旅行なら `## 前日まで` `## 当日` `## 着いてから`、買い物なら `## 買う` `## 買った`）。
作ったら `updated` を今日にする。同じ名前のスペースがもうあれば、作り直さずにそれを使う。

## 頼まれ方と動き

- 「〇〇のスペース作って」→ 型で作り、どんな見出しにしたかを1行で返す。中身の提案（例：出張なら持ち物と乗り継ぎ）を最初に3〜5件入れてよい
- 「〇〇に △△ 入れといて」→ `## 候補` に1行足す。調べてから入れるよう頼まれたら、調べた出どころを行の最後に付ける
- 「△△ 終わった／やめた」→ `## 済み` へ移して `[x]`（やめたものは消さず「— 見送り」）
- 「〇〇見せて」→ 見出しごとに件数と中身を返す。Discord なら長い一覧は表の画像（`table2png.py`）にして要点を2〜3行添える
- 「スペース一覧」→ `スペース/` のファイル名と件数だけ

## 決まった時間に足してもらう（定期実行）

「毎朝AIのニュースから企画を3つ考えて企画ストックに入れて」のように**時間＋スペース**の頼みは、
`fox-routine` で登録する（Mac と Windows）。持ち主にコマンドを打たせない。
Windows では道具の場所が `~/Tools/fox-kit/tools/fox-routine/routine.py` になる（下の `~/Tools/fox-routine/` を読み替える）。

```sh
python3 ~/Tools/fox-routine/routine.py add --name "AIニュースから企画" --at 7:30 --days 毎日 \
  --prompt "ここ1日のAIの主なニュースを調べ、YouTube の企画を3つ考える。出どころを付ける" --space "YouTube企画ストック"
python3 ~/Tools/fox-routine/routine.py list      # 登録の一覧
python3 ~/Tools/fox-routine/routine.py remove 名前
python3 ~/Tools/fox-routine/routine.py run 名前  # いま1回だけ試す（登録したら1回は試して結果を見せる）
```

- `--days` は `毎日`・`平日`・`月,木` など。`--space` を付けないと、結果は保存先の `定期のしごと/<名前>/` に残してお知らせするだけ
- 定期実行で使える道具は「読む・ウェブで調べる・スペースに書く」だけ。メールを送る・予定を変える・支払うことはできない、と頼まれた時点で伝える
- 1回ごとに AI を使う。登録は10本まで。毎日動くものを3本より多く頼まれたら、回数（月およそ何回）を伝えてから登録する
- Mac は launchd、Windows はタスク スケジューラ（`fox-routine-…`）に入る。どちらもパソコンが寝ていた分は、起きたときに1回だけ動く
