# 資料の品質ループ（チェック役を立てて、課題が出なくなるまで回す）

持ち主から何度も頼まれてきたことを、既定の動作にしたもの:
- 「立場の違う人たちでチェックして、改善点が出てこない状態になるまで何度も回して」
- 「入れた修正がちゃんと反映できているか、チェックする人を立てて」
- 「関係者の誰が読んでも疑問が出ないように」

→ **これは毎回やる既定動作。依頼文に書かれていなくても回す。** 説明を求めない。

---

## 手順

### 0. 着手前（1分で済ませる）
- 資料の**読み手**と**この資料を読んだ後に取ってほしい行動**を1行で書く。（例：「関係者全員が、テストの目的と測る数値を理解して始められる」）
- 依頼の型4行（誰が喋るか／中身／寄せる既存資料／いつ要るか）が埋まらない時だけ、一番効く1つを聞く。それ以外は合理的な既定で進める。
- 添削・修正依頼のときは、指示を**1件ずつの台帳**に割る（録音・LINE・チャットの原文を引用、番号を振る）。

### 1. ロールを決める（3〜5役）
[roles.md](roles.md) から資料の種類に合わせて選ぶ。**必ず入れる2役**:
- **読み手代表**（その資料を実際に受け取る人。初見で、前提知識なし）
- **完了チェック役**（添削・指示の反映がある時。指示台帳と現物を1件ずつ突合）

### 2. 並列でレビューさせる
- `shiryo-reviewer` サブエージェントを**ロールごとに1体、同一メッセージで並列起動**する。
- 渡すもの：ロール定義／読み手と目的の1行／現物のパス（HTMLならページごとのスクショPNGも。Chrome のヘッドレス撮影など）／指示台帳／[checklist.md](checklist.md)。
- **前の周の自分の弁明は渡さない**（独立性を保つ）。前周の指摘台帳は「解決済みの再発チェック用」にだけ渡す。

### 3. 指摘を自分で裁く（ここを飛ばさない）
全指摘を1つの**指摘台帳**にまとめ、1件ずつ判定する:
- **採用** → 直す
- **却下** → 理由を1行（レビュー役は平気で間違える。正しい数字を「誤記」と断定することがある。**数字の指摘は必ず自分で検算**）
- **施主判断** → 自分では決められない（事実の確認、方針の選択、未公開の数字）。直さず「持ち主に聞くこと」へ回す
- 重複はまとめる。好みの揺れ（Aさんは増やせ・Bさんは削れ）は**読み手代表の側**に寄せる

### 4. 直す
- 直し方の優先順：**削る > 言い換える > 構造を変える > 足す**（「文字が多くてパッと分からない」が最頻の指摘）
- 見た目の修正は該当ページ限定で。全体CSSは最後の手段（他ページを壊す）
- 直した後、HTML/スライドなら**全ページを機械点検**（見切れ・潰れ・小さすぎ＝0件まで。各要素のはみ出しを測るスクリプト等）
- 前版より悪化していないかを見る（「さっきまでの方が見やすかった」と言われないように）。大きく変えたページは前版と並べて比べる

### 5. 再レビュー → 収束判定
- 同じロール構成で、**新しいエージェント**に現物だけを見せて再度レビュー。
- **止める条件（すべて満たす）**:
  1. 重大（誤り・読み手が止まる・見切れ）と中（分かりにくい・根拠不足）が**新規0件**
  2. 前周に解決した指摘が再発していない
  3. 残りは「却下（理由つき）」「施主判断」「軽微な好み」だけ
- **打ち切り条件**：5周回しても収束しない、または同じ指摘が2周続けて出て直せない → 構造的な問題なので止めて持ち主に「決めることは1つ」の形で上げる。
- 軽微だけが出続ける状態は収束とみなす（無限に回さない）。

### 6. 報告（持ち主へ）
短く、この順で:
1. 完成物（URL・パス。**開いて見せる**）
2. 何周回したか・ロール・周ごとの新規指摘件数（例：`1周目 23件 → 2周目 7件 → 3周目 0件`）
3. 効いた修正トップ3（1行ずつ）
4. **持ち主に決めてほしいこと**（施主判断に回したもの。なければ「なし」）
5. 却下した指摘は件数だけ（聞かれたら台帳を出す）

指摘台帳は成果物の横に `_review/ledger.md` として残す（次に直す時に再発チェックに使う）。

## 簡易版（軽微な修正・1〜2ページだけ）
ロールは「完了チェック役」＋「読み手代表」の2体、1〜2周。機械点検は必ずやる。

## やってはいけない
- チェック役の指摘を検算せずに鵜呑みにする
- 施主判断の事項（数字・方針・事実）を推測で埋めて「解決」扱いにする。**数字を捏造しない**。未確認は★で明示
- 「収束しました」と言いながら、最終周のレビューを回していない
- 周回のたびに資料が長くなる（足す方向に逃げない）
