# ロール表（資料の種類ごとに3〜5役を選ぶ）

各ロールは「誰として」「何を見るか」「どういう時に指摘するか」をサブエージェントに渡す。

## 共通（ほぼ毎回入れる）
| ロール | 見るもの |
|---|---|
| **読み手代表（初見）** | 前提知識ゼロで最初から読む。止まった場所・意味が分からない語・「で、何？」と思ったページを全部挙げる。**1ページ目で何の資料か分かるか** |
| **完了チェック役** | 指示台帳の1件ずつについて、現物で「反映済／一部／未反映／指示と違う形」を判定。証拠（ページ番号・該当文言）つき |
| **ファクト・数字チェック** | 数字の計算・単位・通貨・日付・固有名詞表記。**出典があるか、推定なら推定と書いてあるか**。ページ間で同じ数字が食い違っていないか |
| **アートディレクター** | 1ページ1メッセージか／文字量／視線の流れ／余白／左右のバランス／表記の揃い／区切り線や装飾の品位（太い線はダサい）／図やグラフで直感的に分かるか |

## 資料の種類別に足す
| 資料 | 追加ロール |
|---|---|
| **営業資料・プレセール・投資家向け** | 営業担当（これで商談を進められるか・現場で突っ込まれる箇所）／営業戦略（誰に何を約束しているか・競合との比較で弱い点）／投資家本人（リスクと出口が見えるか） |
| **企画書・テスト計画・新規事業** | プロジェクトマネージャー（目的・期間・役割分担・判断基準が揃っているか。**テストで取る数値と合否ライン**があるか）／各担当（現場の実行者として明日から動けるか）／経営者（お金の流れ・投資額・撤退条件） |
| **社内進捗・役員会** | 役員（1枚で状況と判断事項が掴めるか）／担当者本人（事実と違わないか・発言の主語の切り分け） |
| **銀行・補助金・行政提出** | 審査担当（要件の充足・根拠資料・数字の整合性・様式） |
| **チラシ・SNS・一般向け** | 初めて見る一般客（3秒で何のイベントか・日時場所料金が分かるか）／デザイナー |
| **講演・登壇** | 聴衆（高校生など実際の聴き手）／話し手本人（話しやすい流れか・時間に収まるか） |
| **骨子・MD設計書（デザイン前）** | 受け取るデザイナー（これだけでページを起こせるか。各ページで**何を話し・どういう気持ちにさせるか**が書いてあるか）／すり合わせ相手 |

## ロールに渡す出力形式（固定）
```
[重大|中|軽微] p<ページ> <指摘1行>
  根拠: <どこを見てそう思ったか。引用>
  提案: <直し方を1行。削る方向を優先>
```
最後に「この資料の点数（10点満点）と、あと1つだけ直すなら何か」を書かせる。
